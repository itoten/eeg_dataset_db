# 0003 使えないデータセットも消さずに登録し、区別できるようにする

状態: 決定(2026-11-16、maintainer の指示「信号がない・中身がないなど実際に使えないデータセットも、DB に登録しておけば、使えないことが分かるだけで価値がある。ただし、ほかのデータセットと明確に区別できるようにして、利用者が混乱しないように」による)
関連: [0002](0002-align-with-ser-principles.md)(原則。網羅性と透明性)、[plans/0002](../plans/0002-documents-check-survey.md)(資料調査)

## 1. 何が決まったか

- 資料調査の照合で「EEG の信号がない」「動物」「まだ公開されていない」などと分かったデータセットは、DB から**消さない**。
  それまでの照合で消していた 237 件は、git の履歴から戻した(同じ配布 URL・DOI をもつ重複の記録 8 件は、同じ記録なので戻していない)。
- `datasets.content_class` 列で、**そのデータセットが実際に何を配っているか**を示す。他の列と同じく、値には出典の引用が要る。
  空欄は「まだ判定していない」。

| 値 | 意味 |
|---|---|
| `eeg_signals` | 人の EEG・iEEG・ECoG(睡眠ポリグラフに含まれる EEG を含む)の信号を配っている。生でも処理済み(フィルタ・エポック・平均・スペクトログラム・帯域パワーの時系列)でもよい |
| `no_eeg_signals` | EEG の信号は配っていない。コード、文書、論文、特徴量・統計・結合行列、EEG 以外のデータだけ |
| `non_human` | 信号が生きた人のものではない。動物、ファントム(模型の頭)、シミュレーション |
| `not_released` | 公開を予告しているが、まだ手に入らない |

## 2. 理由

- **網羅性**: 「使えない」と分かることも、利用者にとっては調べた結果である。消すと、次に誰かが同じものを見つけて、同じ調査をやり直す。
- **透明性**: DB は、集めたものと集めなかったものの理由を説明できるべきである。消した理由は git の履歴にしかなく、利用者には見えなかった。
- **混乱を避ける**: 一覧に混ざると「使えない」と気づかずに選ぶ。そこで、サイトでは既定で使えないものを隠し、1 回の操作で見せる。
  使えないものには、名前の横に必ず印を付ける。

## 3. 決め方(中身をどう判定するか)

- 判定は、資料調査の照合担当(AI)の verdict と、その引用による。`tools/audit/apply.py` が、引用が資料の本文にあるときだけ値を入れる。
  題名だけを根拠にした判定は、種(動物)を除いて受け付けない。
- 判定が割れるものは `eeg_signals` に倒す。信号の一部だけを配るもの、処理済みの信号は使える側とする。
  申請すれば生の EEG が手に入るものは、入手経路(`access_routes`)の問題であり、`no_eeg_signals` にしない。
- 引用で決まらないものは空欄のまま。(DB は事実を作らない。)
- どこまでを「処理済みの信号」と呼ぶかは、maintainer の判断が要る。スペクトログラムだけ、図用の配列だけ、単一ニューロンの記録などを `state` の確認事項に挙げてある。

## 4. 影響

- `views/datasets_wide.csv` に `content_class` が入る。`access_summary` は、`eeg_signals` と空欄だけを数える(使えないものは入手の難しさを論じても意味がない)。
- 公開ページは、既定で `eeg_signals` と空欄だけを表示し、「使えないデータセットも表示」で全部見せる。使えないものには印が付く。
- 動物のデータセットは、すでに見つかったものを登録した。**動物の EEG データを探しに行くことはまだしない**(範囲の判断は別)。
- 実装調査(ESPnet のレシピ)の対象は `eeg_signals` だけである。

## 5. 追記(2026-11-16): 「使えない」と書かない

maintainer の指摘「使うかどうかは判断になるので気をつけて」による。DB とページは使うかどうかを判断しない。
ページとスキーマの説明では「使えない」と書かず、資料が書いていること(EEG の信号を含まない、人以外の記録、まだ公開されていない)をそのまま書く。
既定で隠すものの定義はページの絞り込み欄に書き、詳細画面では根拠(`content_class` の行)を示す。
この文書の題と §1〜4 の「使えない」は、maintainer の最初の指示の言葉として残す。
